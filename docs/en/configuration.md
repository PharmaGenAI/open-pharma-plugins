# Configuration

Use the installer's **Configure** action or write `KEY=VALUE` lines to `~/.open-pharma-plugins/config`. The file is written with mode `0600`; its directory uses `0700` where supported. Process environment variables override the same keys in the file.

`OPEN_PHARMA_CONFIG=/path/to/file` selects another file. `OPEN_PHARMA_CONFIG_DIR=/path/to/dir` changes the default configuration directory. These bootstrap variables must be in the process environment.

## File syntax

Put one `KEY=VALUE` pair on each line. Keep comments on separate lines: text after a value, including
`#`, is parsed as part of that value. Use the installer's **Configure** action when possible.

`ci_status` reports whether a provider key is present, not whether the provider accepts it. If
openFDA coverage is `failed`, verify or remove `OPENFDA_API_KEY` from the winning source. Environment
variables override this file. Restart the host, confirm the expected status, and create a new run.

Leave `OPEN_PHARMA_SEARCH_BACKEND` unset or set it to `auto` to select the first configured provider in this order: Serper, Tavily, Exa. Setting a provider name disables fallback when its key is missing.

Search and synthesis are independent. Exa can collect web evidence without an LLM key. The HCP batch
script contacts the configured OpenRouter-compatible endpoint only when `--synthesize` is supplied;
its default model is the pinned `deepseek/deepseek-v4-flash-0731`. Extraction and synthesis default
to `high` reasoning effort and a 120-second request timeout, with SDK automatic retries disabled. Use
`--reasoning-effort xhigh` or `--synthesis-timeout-seconds <seconds>` for deliberate per-run
overrides; the batch manifest records the effective endpoint, model, reasoning effort, and timeout.
