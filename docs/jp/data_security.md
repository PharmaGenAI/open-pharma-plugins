# データセキュリティとコンプライアンス境界

Open Pharma Plugins はローカル実行・保存を基本としますが、一部ツールは公開 API または設定済み
検索プロバイダーへクエリを送信します。データと用途が法域および組織方針で許可されるかは利用者が
判断してください。

## ローカル保存

可変データは既定で `~/.open-pharma-plugins` 配下に保存されます。対象は HCP エンリッチメント、
トレーニング内容と出力、キャンペーンブリーフと資産、エンゲージメントプラン、テリトリーシナリオ、
競合インテリジェンスのウォッチリスト・キャッシュ・レポートです。POSIX 権限を利用できる場合、
ディレクトリは `0700`、ファイルは `0600` です。暗号化、バックアップ、テナント分離、端末保護、
企業アクセス制御を代替するものではありません。

PDF、PPTX、CSV、競合インテリジェンスのソースファイルを取り込むツールは、MCP サーバープロセスが
アクセスできるパスを読み取れます。最小権限のファイルシステムアクセスで実行し、承認前にパス引数を
確認し、無関係な機密ファイルを読み取り範囲外に置いてください。

## 外部送信

PubMed、ClinicalTrials.gov、ORCID、NIH RePORTER、openFDA、DailyMed、選択した Web 検索
プロバイダーにはリクエストに必要な検索語が送られます。資格情報、機密戦略、私有ソース文書、不要な
個人データを検索語に含めないでください。各プロバイダーの規約と保持方針は別途適用されます。

競合インテリジェンスのキャッシュキー、エビデンス URL、実行マニフェスト、レポートマニフェストは、
資格情報らしいクエリパラメーターを除外します。API 資格情報はローカルプロセス、設定、送信要求だけに
保持されます。

プロバイダーの HTTP エラーはエビデンスへ記録する前に秘匿されます。`ci_status` が示すのはキーの
有無であり、有効性ではありません。失敗したソースの診断中にキーを表示してはいけません。キーを
削除する場合は、設定ファイルと優先される環境変数の両方を消去し、ホスト再起動後に状態を確認してから
新しい実行を作成します。

実行とレポートのディレクトリは非上書きで、ハッシュにより関連付けられます。ただし、自動失効や暗号化は
行われません。ハッシュ一致は成果物の関連を示しますが、ソースの真実性やレビュー承認は証明しません。

HCP バッチの生データ収集では LLM を呼び出しません。パッケージ済み
`open-pharma-plugins-hcp-batch` コンソールに `--synthesize` を付けると、選択したアカウント項目と
収集済みエビデンスが設定済みの OpenRouter 互換エンドポイントへ送信されます。運用データを合成する
前に、エンドポイント、モデル、プロバイダーのログ・保持条件、組織の承認を確認してください。
schema-v2 バッチマニフェストには実際のエンドポイント、モデル、reasoning effort、リクエスト
タイムアウトが記録されますが、API キーは記録されません。生成されたアカウント JSON、サマリー CSV、
マニフェストには個人/公開ソースデータが含まれる場合があります。承認済みストレージへ保存し、ローカル
ファイル権限を企業アクセス制御として扱わないでください。詳細は
[HCP バッチ処理](hcp_batch.md)を参照してください。

Territory Alignment の HTML マップを開くと、完全性検証付き Leaflet 資産と
CARTO/OpenStreetMap タイルを公開ネットワークから取得します。タイル提供者はネットワークおよび
マップタイル要求を観測できます。テリトリー座標を送信できない場合は、承認済みのオフライン地図
スタックを使用してください。

## プライバシー、保持、医薬品コンテンツ

- 明確な目的に必要な最小限の個人データだけを扱い、保存前に HCP の本人性と出典を確認します。
- プラン実行前に同意、配信停止、雇用関係、テリトリールールを確認します。
- 既定ディレクトリが不適切なら、承認済みの暗号化または管理ストレージを指定します。
- 運用記録は自動失効しません。組織の保持方針に従い、機能ディレクトリ、出力コピー、バックアップを
  削除します。
- Campaign Studio と Field Training の検証は防御層であり承認ではありません。配布または現場利用前に
  有資格の医学・法務・薬事レビューが必要です。
- 同梱のクレーム、文書、アカウント、HCP、担当者、競合は架空データであり、実運用に使えません。

資格情報が漏えいした可能性がある場合は、プロバイダーで失効し、関連キャッシュを消去して組織の
インシデント対応を実施してください。ローカルファイルの削除だけでは資格情報やプロバイダーログは
消えません。
